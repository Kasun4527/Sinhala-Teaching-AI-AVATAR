MnO₄⁻ හා CrO₄²⁻ වල වර්ණ ඇති වීම සිදු වන්නේ d කාක්ෂික අතර ඉලෙක්ට්‍රෝන සංක්‍රමණ නිසා නොවේ.

සියලු සංයෝජනා ඉලෙක්ට්‍රෝන ඉවත් වීමෙන් පළමුවන මූලද්‍රව්‍ය හතර ඔක්සයිඩ නිපදවයි. ප්‍රධාන කාණ්ඩ මූලද්‍රව්‍ය මෙන් නොව, ආන්තරික මූලද්‍රව්‍යවලට විවිධ ඔක්සිකරණ අංක ඇත. සමහර d ගොනුවේ මූලද්‍රව්‍ය ලෝහ පරමාණුවලට ඔක්සිකරණ අංක දෙකක් සහිත ඔක්සයිඩ සෑදිය හැකි ය. KMnO₄ දම් පැහැති ඝනයකි. MnO₄⁻ වල වර්ණයට හේතු වන්නේ මධ්‍ය Mn පරමාණුව හා O බන්ධ කාණ්ඩ අතර ඉලෙක්ට්‍රෝන සංක්‍රමණයයි. ආම්ලික මාධ්‍යයේ පර්මැංගනේට් අයනයට ප්‍රබල ඔක්සිකාරක ලෙස ක්‍රියා කළ හැකි ය. MnO₂ හා KMnO₄වල වර්ණ පහත දැක්වේ.

[IMAGE: IMAGE_618.png]

MnO₄⁻ වල සමහර වැදගත් රීඩොක්ස් ප්‍රතික්‍රියා පහත දැක්වේ.

ආම්ලික තත්ත්ව යටතේ:

2MnO₄⁻(aq) + 5H₂O₂(l) + 6H⁺(aq) → 2Mn²⁺(aq) + 5O₂(g) + 8H₂O(l)

2MnO₄⁻(aq) + 5H₂S(g) + 6H⁺(aq) → 2Mn²⁺(aq) + 5S(s) + 8H₂O(l)

2MnO₄⁻(aq) + 5SO₂(g) + 2H₂O(l) → 2Mn²⁺(aq) + 5SO₄²⁻(aq) + 4H⁺(aq)

MnO₄⁻(aq) + 5Fe²⁺(aq) + 8H⁺(aq) → Mn²⁺(aq) + 5Fe³⁺(aq) + 4H₂O(l)

2MnO₄⁻(aq) + 10I⁻(aq) + 16H⁺(aq) → 2Mn²⁺(aq) + 5I₂(aq) + 8H₂O(l)

2MnO₄⁻(aq) + 5NO₂⁻(aq) + 6H⁺(aq) → 2Mn²⁺(aq) + 5NO₃⁻(aq) + 3H₂O(l)

2MnO₄⁻(aq) + සාන්ද්‍ර 16HCl(aq) → 2Mn²⁺(aq) + 5Cl₂(g) + 6Cl⁻(aq) + 8H₂O(l)

2MnO₄⁻(aq) + 5C₂O₄²⁻(aq) + 16H⁺(aq) → 2Mn²⁺(aq) + 10CO₂(g) + 8H₂O(l)

මේ සියලු ප්‍රතික්‍රියාවල ආම්ලික තත්ත්ව යටතේ MnO₄⁻, Mn²⁺ බවට ඔක්සිහරණය වේ.


තනුක ක්ෂාරීය තත්ත්ව යටතේ:

2MnO₄⁻(aq) + I⁻(aq) + H₂O(l) → 2MnO₂(s) + IO₃⁻(aq) + 2OH⁻(aq)

2MnO₄⁻(aq) + 3SO₃²⁻(aq) + H₂O(l) → 2MnO₂(s) + 3SO₄²⁻(aq) + 2OH⁻(aq)

ආන්තරික ලෝහ අයනවල සංගත සංයෝග

ආන්තරික ලෝහ අයන ආවේණික සංගත සංයෝග සාදයි. මේ සංගත සංයෝග සංකීර්ණ අයනවලින් සමන්විත වේ. මේ සංකීර්ණ සංයෝග මධ්‍ය ලෝහ අයනයකින් සහ එක දන්තුර ලිගන දෙකකින් හෝ කිහිපයකින් වට වී සැදී තිබේ (මේ ලිගන මඟින් මධ්‍ය ලෝහ අයනය වටා බන්ධන එකක් හෝ කිහිපයක් සාදයි).
උදාහරණයක් ලෙස, [Ni(NH₃)₆]Cl₂, [Ni(NH₃)₆]²⁺ සංකීර්ණ අයනයක් සහ Cl⁻ බාහිර අයන දෙකකින් (රූපය 4.17) සමන්විත වේ.

ලිගන (ලුවිස් භස්ම) මඟින් මධ්‍ය ලෝහ අයනයට ඉලෙක්ට්‍රෝන දායක කර (ලුවිස් අම්ල) එය සමඟ දායක බන්ධන සාදයි.

මේ උදාහරණයේ ඇමෝනියා අණු ඇමීන ලෙස මධ්‍ය පරමාණුව වූ Ni²⁺ බන්ධනය වී ඇත. මේ සංකීර්ණ අයනයේ ආරෝපණය පහත සමීකරණ භාවිත කර පහසුවෙන් ගණනය කළ හැකි ය.

සංකීර්ණයේ ආරෝපණය = මධ්‍ය ලෝහ පරමාණුව හෝ අයනයේ ඔක්සිකරණ අංකය + සියලු ලිගනවල මුළු ආරෝපණය




සරල සංකීර්ණ අයන සහ සංයෝග නම් කිරීම

ලෝහ සංකීර්ණයක නම මඟින් මධ්‍ය ලෝහ අයනයේ ඔක්සිකරණ අංකය, ලිගන වර්ගය සහ සංඛ්‍යාව පිළිබඳ තොරතුරු සපයනු ලබයි. සංකීර්ණ අයනයක නාමය ලිවීමේ දී IUPAC නීති භාවිත කරනු ලැබේ.

ලිගන නම් කිරීම

සංකීර්ණ අයනයක ලිගනයක් ලෙස නම් කිරීමේ දී ඇනායනයේ නමේ අග ඇති අකුර ඉවත් කර අගට 'o' අකුර එකතු කරනු ලැබේ. උදාසීන අණු ලිගන ලෙස ක්‍රියා කිරීමේ දී සාමාන්‍යයෙන් අණුවට දෙනු ලබන නම යොදනු ලැබේ. කෙසේ වෙතත් මේවාට පරිබාහිරව ද නම ඇති නමුත් ඒවා දැනට පවතින අ.පො.ස. (උ.පෙළ) රසායන විද්‍යා විෂය නිර්දේශයේ දී සාකච්ඡා කරනු නොලැබේ.

සීමිත ජලීය NH₃ සමඟ නිල් පැහැති ද්‍රාවණය නිල් අවක්ෂේපයක් බවට පත් වේ.

[Cu(H₂O)₆]²⁺(aq) + 2NH₃(aq) → Cu(OH)₂(s) + 2NH₄⁺(aq) + 4H₂O(l)

වැඩිපුර ජලීය සාන්ද්‍රණය NH₃ සමඟ නිල් පැහැති ද්‍රාවණය තද නිල් පැහැ සංකීර්ණයක් බවට පත් වේ.

[Cu(H₂O)₆]²⁺(aq) + 4NH₃(aq) → [Cu(NH₃)₄]²⁺(aq) + 6H₂O(l)

සාන්ද්‍ර HCl සමඟ නිල් පැහැති ද්‍රාවණය කහ පැහැති ද්‍රාවණයට හැරෙයි.

[Cu(H₂O)₆]²⁺(aq) + 4Cl⁻(aq) → [CuCl₄]²⁻(aq) + 6H₂O(l)

[Zn(H₂O)₆]²⁺ වල ප්‍රතික්‍රියා

ප්‍රබල භස්මයක සීමිත ප්‍රමාණයක් සමඟ අවර්ණ [Zn(H₂O)₆]²⁺ ජලීය ද්‍රාවණය සුදු අවක්ෂේපයක් බවට පත් වේ.

[Zn(H₂O)₆]²⁺(aq) + 2OH⁻(aq) → Zn(OH)₂(s) + 6H₂O(l)

වැඩිපුර ප්‍රබල භස්මයක් සමඟ සුදු අවක්ෂේපය අවර්ණ පැහැදිලි ද්‍රාවණයක් බවට පත් වේ.

Zn(OH)₂(s) + 2OH⁻(aq) → [Zn(OH)₄]²⁻(aq)

අවර්ණ ද්‍රාවණය සුදු අවක්ෂේපයක් බවට පත් වී, පසුව වැඩිපුර භස්මය දැමූ විට ඒ අවක්ෂේපය දිය වී අවර්ණ ද්‍රාවණයක් සාදයි.



d ගොනුවේ මූලද්‍රව්‍යවල වැදගත්කම

1. ආන්තරික මූලද්‍රව්‍ය (Au, Ag හා Cu) හොඳ තාප සන්නායක වන අතර ආන්තරික මූලද්‍රව්‍යවල පරමාණු වේ. තරම සමාන නිසා ඒවා මිශ්‍ර කර මිශ්‍ර ලෝහ සෑදිය හැකි ය. මේ මිශ්‍ර ලෝහ අතීතයේ සිට ම භාවිත කර ඇත. මිශ්‍ර ලෝහ මඟින් ලෝහවල ගුණ වෙනස් කළ හැකි ය.

2. විකිරණ කොබෝල්ට් සමස්ථානික ⁶⁰Co විකිරණ ප්‍රභවයක් ලෙස භාවිත කෙරේ.

3. උත්ප්‍රේරක ගුණ ඇති සංයෝග සංවර්ධනය කිරීම සඳහා ආන්තරික ලෝහ පරමාණු සහ අයන භාවිත කරනු ලබන අතර, මේවා උත්ප්‍රේරක ලෙස විවිධ කර්මාන්තවල දී ද භාවිත කරනු ලබයි.

4. ආන්තරික ලෝහ විවිධ වූ වර්ණවත් සංයෝග සාදන නිසා මේවා තීන්ත නිෂ්පාදනයේ දී වර්ණක ලෙස භාවිත කරනු ලබයි. තව ද මේවා වර්ණවත් වීදුරු සහ වීදුරු බෝතල් නිෂ්පාදනයට ද යොදා ගනු ලැබේ.

5. Ni සහ Cd වැනි d ගොනුවේ මූලද්‍රව්‍ය නැවත ආරෝපණය කළ හැකි කෝෂ නිෂ්පාදනය සඳහා භාවිත කරනු ලැබේ.

6. ආන්තරික මූලද්‍රව්‍ය ප්‍රකාශ වෝල්ටීය කෝෂවල ඇති කැඩ්මියම් ටෙලුරයිඩ් (CdTe) සහ කොපර් ඉන්ඩියම් ඩයිසෙලිනයිඩ් වැනි සංයෝග නිෂ්පාදනයට භාවිතා කරනු ලැබේ. සූර්ය කෝෂ යනු ප්‍රකාශ වෝල්ටීය කෝෂවලට උදාහරණයකි.

d ගොනුවේ තෝරාගත් කැටායන හඳුනා ගැනීමේ පරීක්ෂණ

1. Fe²⁺

Fe²⁺ හඳුනා ගැනීමට K₃[Fe(CN)₆] සමඟ KFe[Fe(CN)₆] තද නිල් අවක්ෂේපය සෑදීම යොදා ගත හැකි ය.

Fe²⁺(aq) + K₃[Fe(CN)₆](aq) → KFe[Fe(CN)₆](s) + 2K⁺(aq)

2. Fe³⁺

Fe³⁺ හඳුනා ගැනීමට K₄[Fe(CN)₆] සමඟ Fe₄[Fe(CN)₆]₃ ප්‍රුසියන් නිල් අවක්ෂේපය සෑදීම යොදා ගත හැකි ය.

4Fe³⁺(aq) + K₄[Fe(CN)₆](aq) → Fe₄[Fe(CN)₆]₃(s) + 4K⁺(aq)

Fe³⁺ හඳුනා ගැනීමට තරමක් දුරට ආම්ලික NH₄SCN ද්‍රාවණය මඟින් [Fe(SCN)(H₂O)₅]²⁺ රතු පැහැ සංකීර්ණය සෑදීම යොදා ගත හැකි ය.

[Fe(H₂O)₆]³⁺(aq) + NH₄SCN(aq) → [Fe(SCN)(H₂O)₅]²⁺(aq) + NH₄⁺(aq)

3. Cr³⁺

Cr³⁺ ඔක්සිකරණය වී කහ පැහැති ද්‍රාවණයක් වූ CrO₄²⁻ සාදයි. Cr³⁺ ද්‍රාවණයට වැඩිපුර සෝඩියම් හයිඩ්‍රොක්සයිඩ් එකතු කර, ඊට පසු 6% හයිඩ්‍රජන් පෙරොක්සයිඩ් ස්වල්පයක් එකතු කළ විට කහ පැහැති CrO₄²⁻ සාදේ.
