16 වන කාණ්ඩයේ මූලද්‍රව්‍ය

16 වන කාණ්ඩයේ නැඹුරුතා

16 වන කාණ්ඩයේ ප්‍රථම මූලද්‍රව්‍ය වන ඔක්සිජන් කාණ්ඩයේ අනෙකුත් මූලද්‍රව්‍යවලින් වෙනස් වූ ලක්ෂණ දක්වයි.
කාණ්ඩයේ පහළට යත් ම ලෝහමය ස්භාවය වැඩි වේ. කෙසේ වෙතත්, 16 වන කාණ්ඩයේ එකදු මූලද්‍රව්‍යයක් වත් සැබෑ ලෝහ ලෙස ක්‍රියා නොකරයි.
ඔක්සිජන් හා සල්ෆර් යන දෙවර්ගය ම අලෝහ වන අතර, කාණ්ඩයේ අනෙක් මූලද්‍රව්‍ය ලෝහමය හා අලෝහමය ලක්ෂණ පෙන්නුම් කරයි.
ඔක්සිජන් පමණක් වායුවක් ලෙස පවතින අතර කාණ්ඩයේ අනෙක් මූලද්‍රව්‍ය ඝන අවස්ථාවේ පවතී. ඔක්සිජන් හැර කාණ්ඩයේ අනෙකුත් මූලද්‍රව්‍යවලට -2 සිට +6 දක්වා වූ ඉරට්ටේ සංඛ්‍යා ඔක්සිකරණ අවස්ථා ලෙස දැක්විය හැකි ය.
ඔක්සිකරණ අවස්ථාව +6 හා -2 හි ස්ථාවරත්වය කාණ්ඩයේ පහළට යත් ම අඩු වන අතර +4 ඔක්සිකරණ අවස්ථාවේ ස්ථාවරත්වය වැඩි වේ.

16 වන කාණ්ඩයේ හයිඩ්‍රයිඩ

16 වන කාණ්ඩයේ මූලද්‍රව්‍ය හයිඩ්‍රජන් සමඟ සරල හයිඩ්‍රයිඩ සාදයි. මේවා සියල්ල සහසංයුජ හයිඩ්‍රයිඩ වේ.
කාණ්ඩය දිගේ පහළට යන විට හයිඩ්‍රයිඩවල තෝරා ගත් ගුණවල විචලන වගුව මඟින් දැක්වේ.

[IMAGE: IMAGE_592.png]

කාණ්ඩයේ අනෙක් හයිඩ්‍රයිඩවලට වඩා ශක්තිමත් හයිඩ්‍රජන් බන්ධන හේතුවෙන්, H₂O අසාමාන්‍ය ලෙස ඉහළ ද්‍රවාංක හා තාපාංක පෙන්වයි.
කාණ්ඩයේ සියලු හයිඩ්‍රයිඩ අතුරින් විෂදායී නොවන්නේ ජලය පමණි. මධ්‍ය පරමාණුවේ ප්‍රමාණය විශාල වීම හේතුවෙන් සහසංයුජ හයිඩ්‍රයිඩවල බන්ධන දිගෙහි නිරීක්ෂිත විචලනය ඇති වේ.
ඒ නිසා කාණ්ඩයේ පහළට බන්ධන දිග වැඩි වේ. කාණ්ඩය ඔස්සේ පහළට මධ්‍ය පරමාණුවේ විද්‍යුත් ඍණතාව අඩු වීමේ ප්‍රතිඵලයක් ලෙස බන්ධන ඉලෙක්ට්‍රෝනවල පවත්නා අඩු විකර්ෂණ හේතුවෙන් කාණ්ඩයේ පහළට බන්ධන කෝණය අඩු වේ.
H₂S, H₂Se හා H₂Te හි බන්ධන කෝණය 90° ට ආසන්න වේ.
විශේෂයෙන් හයිඩ්‍රජන් හා බැඳීමේ දී බොහෝ සෙයින් සෙලීනියම් හා ටෙලියුරියම්වල P කාක්‍ෂික පැවතීම මේඟින් හෙළි වේ. 



ඔක්සිජන්

ඩයිඔක්සිජන් (O₂) හා ට්‍රයිඔක්සිජන් (මෙසෝන් O₃) යනුවෙන් ඔක්සිජන් සතු බහුරූපී ආකාර දෙකක් ඇත.
ඩයිඔක්සිජන් යනු අවර්ණ හා ගන්ධයකින් තොර ජලයේ අල්ප වශයෙන් ද්‍රාව්‍ය වායුවකි. ඕසෝන් සතුව කටුක ගන්ධයක් ඇත. ඕසෝන්හි බන්ධන කෝණය 111.5° කි.
මේ බහුරූපී ආකාර දෙකෙහි ව්‍යුහ පහත දී ඇත.

[IMAGE: IMAGE_593.png]

පොටෑසියම් ක්ලෝරේට්හි උත්ප්‍රේරක වියෝජනය හා හයිඩ්‍රජන් පෙරොක්සයිඩ් ඔක්සිජන් නිපදවීම සඳහා යොදා ගත හැකිය.

2KClO₃(s) → 2KCl(s) + 3O₂(g), MnO₂ හෝ Pt හමුවේ රත් කිරීම

2H₂O₂(aq) → 2H₂O(l) + O₂(g), MnO₂ හෝ Pt හමුවේ රත් කිරීම

ලෝහ ඔක්සයිඩ නිපදවමින් ලෝහ ඩයිඔක්සිජන් සමඟ ප්‍රතික්‍රියා කරයි. ඕසෝන් යනු ඩයිඔක්සිජන්වලට වඩා ප්‍රබල ඔක්සිකාරකයකි. සංවර්ධිත රටවල් රැසක ජලයේ ක්ෂුද්‍ර ජීවීන් නසන විසබීජ නාශකයක් ලෙස ඕසෝන් භාවිත කෙරේ. ක්ලෝරීන් මෙන් නොව, විසබීජ නාශක ක්‍රියාවලියේදී ඕසෝන් කිසිදු හානිදායක අතුරුඵලයක් නිපදවන්නේ නැත.




සල්ෆර්

පහත විස්තර කර ඇති ආකාරයට සල්ෆර් වර්ගීකරණය කළ හැකි ය.

[IMAGE: IMAGE_594.png]

ඔක්සිජන් මෙන් නොව, සල්ෆර් සිය පරමාණු සමඟ ද්විත්ව බන්ධන සාදනවාට වඩා එක බන්ධන සාදයි.
වඩාත්ම සුලබ බහුරූපී ආකාරය වන්නේ α-සල්ෆර් (α-S₈) යනුවෙන් හැඳින්වෙන රොම්බසිය සල්ෆර්ය. පහත පෙන්වා දී ඇති පරිදි එය සල්ෆර් පරමාණු අටකින් සමන්විත වක්‍රිය අක්වක් සැකසුමකින් යුත්, ඔටුන්නක හැඩයෙන් යුක්ත වේ.
93 °C ට වඩා ඉහළ උෂ්ණත්වයට රත් කිරීමේදී සුලබව හමු වන අනෙක් බහුරූපී ආකාරය වන ඒකානති සල්ෆර් β-සල්ෆර් (β-S8) බවට සිය ඇසුරුම් ආකාරය වෙනස් කර ගනී. මේ ආකාර දෙක එකිනෙකෙහි බහුරූපී ආකාර වේ.

[IMAGE: IMAGE_595.png]

රොම්බසිය හා ඒකානති යන ස්ඵටිකරූපී ආකාර ඔටුනු හැඩයේ S₈ වක්‍රවලින් සමන්විත වේ. මේ වක්‍ර 95 °C ට පහළ උෂ්ණත්වවලදී සල්ෆර්වල වඩාත්ම ස්ථාවර අස්ඵටිකරූපී සල්ෆර් යනු විලීන සල්ෆර්වල සුවිකාර්ය ආකාරයයි.

සංවෘත දාම සහිත විලීන සල්ෆර් ක්ෂණිකව සිසිල් කිරීමේදී ද්‍රව සල්ෆර් විවෘත දාම සහිත තාප සුවිකාර්ය සල්ෆර් බවට පරිවර්තනය වේ. කාලය ගතවත්ම සුවිකාර්ය සල්ෆර් ස්ඵටිකරූපී සල්ෆර් බවට හැරේ. සල්ෆර්වල අස්ඵටිකරූපී ආකාරය ආතනය වන නමුත් අස්ථායී වේ.


ඔක්සිජන් අඩංගු සංයෝග

ජලය සහ හයිඩ්‍රජන් පෙරොක්සයිඩ්

පහත රූපයේ H₂O හා වායුමය H₂O₂ ව්‍යුහය දැක්වේ.

[IMAGE: IMAGE_596.png]

ජලය යනු වැඩිපුරම භාවිත වන දාවකයයි. ජලය පහත පරිදි අයනීකරණය වේ. මෙය ජලයේ ස්වයං අයනීකරණය ලෙස හැඳින්වේ.

2H₂O(l) ⇌ H₃O⁺(aq) + OH⁻(aq)

උභය ප්‍රෝටීක අණුවකට ප්‍රෝටෝනයක් දායක කිරීම හෝ ප්‍රතිග්‍රහණය කිරීම සිදු කළ හැකි ය. ඒ නිසා එයට අම්ලයක් ලෙස හා භාස්මයක් ලෙස හැසිරිය හැකි ය. ප්‍රෝටෝනයක් ප්‍රතිග්‍රහණය කිරීමේ හා මුදා හැරීමේ හැකියාව ඇති බැවින් ජලය උභය ප්‍රෝටීක සංයෝගයක් වේ.

H₂O(l) + HCl(aq) → H₃O⁺(aq) + Cl⁻(aq)

H₂O(l) + NH₃(aq) ⇌ NH₄⁺(aq) + OH⁻(aq)



හයිඩ්‍රජන් පෙරොක්සයිඩ්

හයිඩ්‍රජන් පෙරොක්සයිඩ් යනු ඒකතලීය නොවන අණුවකි. (H₂O₂) එකම තලයේ නොපවතින OH කාණ්ඩ දෙකකින් H₂O₂ අණුව සමන්විත අතර, වායුමය අවස්ථාවේදී H-O-O බන්ධන කෝණය 94.8° වන කෝණික හැඩයෙන් යුක්ත වේ. ඔක්සිජන් පරමාණු මත පවතින එකසර යුගල අතර විකර්ෂණ අවම වන පරිදි සැකසුණු ව්‍යුහය රූපය 4.13 හි දැක්වේ. 'O' H-O කාණ්ඩ දෙක එකිනෙක අතර ද්විතල කෝණය 111.5° වන සේ පිහිටයි.

ප්‍රබල හයිඩ්‍රජන් බන්ධන හේතුවෙන්, H₂O₂ දුස්ස්‍රාවී ද්‍රවයක් වේ. ඔක්සිකාරකයක් මෙන්ම ඔක්සිහාරකයක් ලෙසත් H₂O₂ වලට හැසිරිය හැකි ය. එය ඔක්සිජන් බවට ඔක්සිකරණය වන අතර, ජලය බවට ඔක්සිහාරණය වේ.

ඔක්සිකරණ අර්ධ ප්‍රතික්‍රියාව:

H₂O₂(aq) + 2H⁺(aq) + 2e⁻ → 2H₂O(l)

ඔක්සිහාරණ අර්ධ ප්‍රතික්‍රියාව:

H₂O₂(aq) → 2H⁺(aq) + O₂(g) + 2e⁻

ද්විධාකරණය:

2H₂O₂(aq) → O₂(g) + 2H₂O(l)

H₂O₂ ඔක්සිකාරකයක් ලෙස:

H₂O₂(aq) + 2H⁺(aq) + 2I⁻(aq) → I₂(aq) + 2H₂O(l)

H₂O₂(aq) + 2H⁺(aq) + 2Fe²⁺(aq) → 2Fe³⁺(aq) + 2H₂O(l)

H₂O₂ ඔක්සිහාරකයක් ලෙස:

2MnO₄⁻(aq) + 5H₂O₂(aq) + 6H⁺(aq) → 2Mn²⁺(aq) + 5O₂(g) + 8H₂O(l)

Cr₂O₇²⁻(aq) + 3H₂O₂(aq) + 8H⁺(aq) → 2Cr³⁺(aq) + 7H₂O(l) + 3O₂(g)





සල්ෆර් අඩංගු සංයෝග



හයිඩ්‍රජන් සල්ෆයිඩ්

හයිඩ්‍රජන් පෙරොක්සයිඩ් යනු නරක් වූ බිත්තර ගන්ධයෙන් යුක්ත, අවර්ණ, විෂදායි හා ආම්ලික වායුවක් වේ. ලෝහ සල්ෆර් ප්‍රබල අම්ල සමඟ ප්‍රතික්‍රියා කරවීමෙන් H₂S නිපදවිය හැකි ය. දුබල ආම්ලික ද්‍රාවණයක් සාදමින් එය ජලයේ දිය වේ.



හයිඩ්‍රජන් සල්ෆයිඩ්වල ප්‍රතික්‍රියා

H₂S ප්‍රබල භාස්ම හමුවේ අම්ලයක් ලෙස:

NaOH(aq) + වැඩිපුර H₂S(g) → NaHS(s) + H₂O(l)

2NaOH(aq) + සීමිත H₂S(g) → Na₂S(s) + 2H₂O(l)

2Na(s) + වැඩිපුර 2H₂S(g) → 2NaHS(s) + H₂(g)

2Na(s) + සීමිත H₂S(g) → Na₂S(s) + H₂(g)

Mg(s) + H₂S(g) → MgS(s) + H₂(g)



H₂S ඔක්සිහාරකයක් ලෙස:

K₂Cr₂O₇(aq) + 4H₂SO₄(aq) + 3H₂S(g) → K₂SO₄(aq) + Cr₂(SO₄)₃(aq) + 3S(s) + 7H₂O(l)

2H₂S(aq) + SO₂(g) → 3S(s) + 2H₂O(l)



සල්ෆර් ඩයොක්සයිඩ්

සල්ෆර් ඩයොක්සයිඩ් අවර්ණ වායුවක් වන අතර, ජලයේ ද්‍රාව්‍ය වේ. ඔක්සිකාරකයක් හා ඔක්සිහාරකයක් ලෙස සල්ෆර් ඩයොක්සයිඩ්වලට ක්‍රියා කළ හැකි ය.




සල්ෆර් ඩයොක්සයිඩ් ප්‍රතික්‍රියා

ඔක්සිකාරකයක් ලෙස:

2Mg(s) + SO₂(g) → 2MgO(s) + S(s)

3Mg(s) + SO₂(g) → 2MgO(s) + MgS(s)

5SO₂(g) + 2KMnO₄(aq) + 2H₂O(l) → K₂SO₄(aq) + 2MnSO₄(aq) + 2H₂SO₄(aq)


3SO₂(g) + K₂Cr₂O₇(aq) + H₂SO₄(aq) → K₂SO₄(aq) + Cr₂(SO₄)₃(aq) + H₂O(l)

SO₂(g) + 2FeCl₃(aq) + 2H₂O(l) → H₂SO₄(aq) + 2FeCl₂(aq) + 2HCl(aq)


සල්ෆර්වල ඔක්සෝ අම්ල

සල්ෆර්වල සුලබ ඔක්සිකරණ අංක -2, 0, +2, +4 හා +6 වේ.

සල්ෆියුරික් අම්ලය යනු ප්‍රබල ද්විප්‍රෝටික අම්ලයකි.

SO₃(g) + H₂O(l) → H₂SO₄(aq)

H₂SO₄(aq) + H₂O(l) → HSO₄⁻(aq) + H₃O⁺(aq)

C₂H₅OH(l) → C₂H₄(g) + H₂O(l), සාන්ද්‍ර H₂SO₄

2H₂SO₄(l) + Mg(s) → SO₂(g) + MgSO₄(aq) + 2H₂O(l)

H₂SO₄(aq) + 2NaOH(aq) → Na₂SO₄(aq) + 2H₂O(l)
